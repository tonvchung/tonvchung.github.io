Privacy Policy — Structured Document Workbench

Last updated: November 19, 2026 · Applies to the Structured Document Workbench browser extension (Chrome Web Store and Microsoft Edge Add-ons)

1. Overview

Structured Document Workbench ("the extension") is a local JSON / XML formatting and document browsing tool. The short version: the extension collects no personal information and transmits nothing to the developer. Everything you paste stays on your own device.

2. No Permissions, No Network

The extension declares no browser permissions and no host permissions. It does not make any network requests: there is no backend service, no analytics endpoint, and no developer server. All parsing, formatting, tree rendering, searching, clipboard, and history features run on built-in browser APIs inside the packaged app window. The extension works fully offline.

3. Data Storage — Local Only

Up to 20 successfully parsed source documents are kept in the extension page's localStorage so you can restore them from the history list. This data:

  • is stored only on your current device, inside your browser;
  • is never uploaded to, or accessible by, the developer;
  • is never synced to any developer-operated server;
  • may be deleted by clearing the extension's data or uninstalling the extension.

4. No Remote Code

All JavaScript, HTML, CSS, icons, and localization files are included in the extension package. The extension does not load remote scripts, dynamically import remote modules, use eval or new Function, or make network requests of any kind.

5. No Third-Party Services

The extension contains no accounts, no identity features, no cookies, no analytics, no advertising, no tracking, and no browsing-history access. You choose what text to paste; that content is processed only on your device and is never transmitted anywhere.

6. Data We Do Not Collect

The developer does not collect, store, or process any of the following: personal identity information, health information, financial information, authentication information, personal communications, location, browsing history, user activity, or website content. No personal information is required to use any feature.

7. Changes to This Policy

If the extension's behavior changes in a way that affects this policy, this page will be updated before the corresponding version is published, with a revised "last updated" date.

8. Contact

For any questions about this privacy policy, you can reach the developer through the support/contact channel listed on the extension's store listing page.

隐私政策 — 结构化文档工作台

最后更新日期：2026 年 11 月 19 日 · 适用于结构化文档工作台浏览器扩展（Chrome 网上应用店及 Microsoft Edge 加载项）

1. 概述

结构化文档工作台（以下简称"本扩展"）是一个本地 JSON / XML 格式化与文档浏览工具。简而言之：本扩展不收集任何个人信息，也不向开发者传输任何数据。您粘贴的所有内容均保留在自己的设备上。

2. 零权限、零网络

本扩展不声明任何浏览器权限和主机权限，也不发起任何网络请求：没有后端服务、没有统计上报端点、没有开发者服务器。所有解析、格式化、文档树渲染、搜索、剪贴板和历史记录功能均在扩展自带的应用窗口内，基于浏览器内置 API 运行。扩展可完全离线使用。

3. 数据存储 — 仅保存在本地

最多 20 条成功解析的源文档会保存在扩展页面的 localStorage 中，以便您从历史记录中恢复。这些数据：

  • 仅存储在您当前设备的浏览器中；
  • 不会上传给开发者，开发者也无法访问；
  • 不会同步到任何由开发者运营的服务器；
  • 清除扩展数据或卸载扩展时可能会被删除。

4. 无远程代码

所有 JavaScript、HTML、CSS、图标和本地化文件均包含在扩展安装包内。扩展不会加载远程脚本、动态导入远程模块，不使用 eval 或 new Function，也不发起任何网络请求。

5. 无第三方服务

本扩展不含账号体系、身份功能、Cookie、统计分析、广告、跟踪或浏览历史访问。粘贴什么内容由您决定，内容仅在您的设备上处理，不会被传输到任何地方。

6. 我们不收集的数据

开发者不收集、存储或处理以下任何信息：个人身份信息、健康信息、财务信息、身份验证信息、个人通讯、位置信息、浏览历史、用户活动记录或网站内容。使用任何功能都不需要提供个人信息。

7. 政策变更

若扩展行为发生影响本政策的变化，将在对应版本发布前更新本页面，并更新"最后更新日期"。

8. 联系方式

如对本隐私政策有任何疑问，可通过扩展商店页面中列出的支持/联系渠道与开发者联系。
